## 📌 Track & Repository Overview

This repository documents the foundational programming curriculum of the **Coding Ninjas Job Bootcamp: Data Science with GenAI**. 

It contains practice notebooks covering fundamental syntax, algorithmic constructs, memory models, object scoping, and I/O pipelines—building the base required for NumPy, Pandas, Machine Learning, and generative LLM fine-tuning pipelines.

* **Bootcamp:** Coding Ninjas — Job Bootcamp Data Science with GenAI
* **Core Language:** Python
* **Primary Environment:** Google Colab (Zero-setup cloud runtime with free GPU acceleration)

---

## 💻 Why Google Colab?

| Feature | Google Colab | Local Environment (VS Code / Anaconda) |
|---|---|---|
| **Setup & Dependencies** | **Instant** — Pre-installed scientific packages | Requires manual virtual envs (`venv`, `conda`) & package installs |
| **Compute & Hardware** | **Free Cloud GPU/TPU (T4)** on demand | Limited to local host CPU and onboard GPU |
| **Portability** | Browser-based, works anywhere | Tied to a specific local machine |
| **GitHub Sync** | Direct commits via `File -> Save a copy in GitHub` | Requires local `git add / commit / push` CLI workflows |

## 🚀 Interactive Syllabus & Colab Notebooks

| # | Topic | Key Focus Areas |
| --- | --- | --- |
| **01** | **Introduction to Python** | Interpreter vs compiler, REPL, execution model, comments, indentation |
| **02** | **Variables and Datatypes** | Dynamic typing, memory allocations (`id()`), typecasting, primitive vs reference types |
| **03** | **Data Structures** | Lists, Tuples, Sets, Dictionaries, comprehension syntax, mutable operations |
| **04** | **Operators** | Arithmetic, relational, logical, bitwise manipulation, identity (`is`), membership (`in`) |
| **05** | **Conditional Statements** | `if`, `elif`, `else` hierarchies, truthy/falsy evaluation, ternary operators |
| **06** | **Looping Statements** | `for`, `while`, sequence iteration, `range()`, `enumerate()`, `zip()` utility patterns |
| **07** | **Control Statements** | Loop control flow with `break`, `continue`, `pass`, and `for...else` / `while...else` constructs |
| **08** | **Functions** | LEGB variable scope, `*args`, `**kwargs`, default parameters, lambda closures |
| **09** | **Exception Handling** | Defensive coding: `try`, `except`, `else`, `finally`, `raise`, custom runtime exceptions |
| **10** | **Modules** | Module import resolution, built-in libraries (`math`, `random`, `os`, `sys`), `__name__ == '__main__'` |
| **11** | **File Handling** | Context manager pattern (`with`), stream operations (`r`, `w`, `a`), structured parsing (CSV/JSON) |
